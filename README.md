# CNN-autoencoder-Malaria
autoencoder to detect Malaria in images of red blood cells

CNN autoencoder was trained on 5000 images of healthy red blood cells.  Model was trained on HSV images but only the saturation channel.  Saturation channel highlighted the Malaria regions best.
CNN autoencoder correctly identified 95% of Malaria images and 90% of healthy cells.  Model was tested on 2600 images.
